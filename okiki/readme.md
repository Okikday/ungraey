# Ungraey — Project Overview
### "Don't trash it, cash it."

---

## What is Ungraey?

**Ungraey** is a decentralized, localized commodity marketplace for everyday upcyclable waste. It empowers everyday people to divert discarded items (cardboard boxes, scrap wood, textiles, clean glass jars, electronics) directly to local creators, artisans, and small businesses who actively need them—and get paid for it.

### Core Architecture
- **Frontend**: Flutter with Riverpod (Pod structure), GoRouter, and the Aura Design System (fluid spring curves, Apple-grade `BackdropShadow`, calibrated luminescence).
- **Backend**: Serverpod 4.0, PostgreSQL persistence, real-time message streams.
- **AI / Computer Vision**: Fast on-device and edge material classification with confidence scores and weight estimation.
- **Security & Reliability**: Cryptographic single-use QR tokens for verified physical handoffs; zero-leak secret handling.
